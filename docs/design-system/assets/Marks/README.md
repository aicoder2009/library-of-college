The product's real icons, generated by `tools/genicons.py` in the repository (Pillow, sampling its palette from the existing files): a bold serif **L** sitting behind an orange highlighter stripe — the same gesture as the `HighlightHeading` component, which is where the mark comes from.

| File | Where it is used |
| --- | --- |
| `favicon-32.png` | Browser tab, 32px |
| `favicon-48.png` | Browser tab at 1.5× and Windows pins |
| `apple-touch-icon.png` | iOS home screen, 180px |
| `icon-192.png` | `manifest.webmanifest`, Android home screen |
| `icon-512.png` | `manifest.webmanifest`, splash and store listing |
| `og-image.png` | `og:image` on the landing page, 1200×630 |

## Rules

- **There is no vector master and no SVG logo.** The mark is raster at these sizes only. If the wordmark changes, rerun the generator rather than hand-editing a PNG or tracing one of these.
- The icons are referenced by root-relative URLs in `index.html`'s `<head>`, and `og:image` points at an absolute URL on the canonical domain. Moving the domain means updating that tag.
- The mark carries its own ink and stripe color; it does not inherit `currentColor` and must not be recolored per theme. It reads on both the light and dark grounds as drawn.
- Where a mark will not fit — a plain-text context, an email signature — set the name in the `serif` family at weight 700 and stroke the initial **L** with `HighlightHeading` in `c0`. Do not redraw the icon.
